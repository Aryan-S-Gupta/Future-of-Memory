# Prerequisites
- download ComfyUI https://www.comfy.org/download
- download dreamshaper model ver 7 https://civitai.com/models/4384?modelVersionId=109123
- put the model under ComfyUI/models/checkpoints
- starts ComfyUI server, make sure it is running at port 8080

# Good to know
- before running the server, make sure you have at least 3 GB of free memory
- the first launch is usually extremely slow and may take several minutes
